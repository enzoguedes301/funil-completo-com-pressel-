📋 RESUMO
═══════════════════════════════════════════════════════════════════════════

Implementação de API PIX dinâmica com QR Code e copy-paste para todo o funnel
de checkout (principal + upsells). Sistema totalmente funcional e pronto para
produção com integração com gateway PIX (Skale/Asaas/Braspag).

🔧 MODIFICAÇÕES NO SERVER
═══════════════════════════════════════════════════════════════════════════

server.js +180 linhas de código

✅ 3 Novos Endpoints API:

  POST /api/createPixPayment
    ├─ Gera novo pagamento PIX dinâmico
    ├─ Retorna: paymentId, QR Code, chave PIX, expiração
    └─ Armazena em pix_payments.json

  GET /api/getPixPayment?id=XXX
    ├─ Consulta status do pagamento
    ├─ Retorna: status (PENDING/CONFIRMED), valores, datas
    └─ Usado para verificação em tempo real

  POST /api/confirmPixPayment
    ├─ Confirma pagamento (para testes ou webhooks)
    ├─ Muda status de PENDING para CONFIRMED
    └─ Dispara redirecionamento automático

✅ Funções Auxiliares:
  ├─ initPixStorage() - Inicializa arquivo de pagamentos
  ├─ loadPixPayments() - Carrega dados persistidos
  ├─ savePixPayments() - Salva dados em disco
  ├─ generatePixCopyPaste() - Gera chave PIX EMV
  └─ generateQrCodeString() - Gera dados para QR Code

💾 ARMAZENAMENTO DE DADOS
═══════════════════════════════════════════════════════════════════════════

Arquivo: pix_payments.json

Estrutura de Pagamento:
{
  "id": "PIX_1234567890_abc123def",          // ID único do pagamento
  "orderId": "ORDER_123",                    // ID do pedido
  "amount": 97.00,                           // Valor em reais
  "customerName": "João Silva",              // Nome do cliente
  "customerEmail": "joao@email.com",         // Email
  "description": "Cartão de Crédito",        // Descrição
  "status": "PENDING",                       // PENDING | CONFIRMED
  "createdAt": "2025-08-25T10:30:00.000Z",  // Data de criação
  "expiresAt": "2025-08-25T11:00:00.000Z",  // Expiração (30 min)
  "paidAt": "2025-08-25T10:35:00.000Z",     // Data do pagamento
  "qrCode": "PIX|97|ORDER_123|...",         // Dados para QR Code
  "pixCopyPaste": "00020126..."              // Chave PIX EMV
}

🧪 COMO TESTAR
═══════════════════════════════════════════════════════════════════════════

1️⃣  Iniciar servidor:
    cmd> node server.js

2️⃣  Acessar checkout principal:
    http://localhost:8080/checkout-pix.html?amount=97&nome=TestClient

3️⃣  Escanear QR Code ou copiar chave PIX:
    → QR Code é gerado dinamicamente via qrcodejs
    → Chave PIX está em formato EMV (padrão BCB)
    → Ambos contêm valor e ID do pedido

4️⃣  Confirmar pagamento (DevTools F12 > Console):
    fetch('/api/confirmPixPayment', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ paymentId: 'PIX_xxx_yyy' })
    }).then(r => r.json()).then(console.log);

5️⃣  Verificar status:
    http://localhost:8080/api/getPixPayment?id=PIX_xxx_yyy
